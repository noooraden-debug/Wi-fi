# WiFi Hub — تحكّم كامل بالراوتر: بلا root، بلا خدمات خارجية

تطبيق عربي (RTL) يتحكّم براوتر **OpenWrt / LEDE** مباشرةً عبر `ubus` من داخل الشبكة،
مع **قاعدة بيانات داخلية** (SQLite) تجمع الحسابات والاشتراكات والأكواد، و**مزامنة لحظية**
بين لوحة الإدارة ولوحة المشترك.

```
المشترك (تطبيق)  ⇄  الخادم الداخلي (Node + SQLite)  ⇄  لوحة الإدارة
        │                                                 │
        └──────── ubus مباشر داخل الشبكة ────────────────┘  (الراوتر)
```

---

## 1) ما الذي بُني بالضبط

| المكوّن | الموقع | الدور |
|---|---|---|
| **الخادم الداخلي** | `server/server.js` | REST + قناة لحظية (SSE) + تقديم الواجهة |
| **قاعدة البيانات** | `server/db.js` | SQLite: مستخدمون · أكواد · اشتراكات · طلبات · جلسات · إعدادات · سجل أحداث |
| **المصادقة** | `server/auth.js` | تجزئة `scrypt` + جلسات + توليد الأكواد |
| **الأحداث اللحظية** | `server/sse.js` | إشعار فوري لكل المتصلين عند أي تغيير |
| **واجهة البرمجة** | `server/server.js` | `/api/*` (انظر §5) |
| **واجهة التطبيق** | `web/index.html` + `web/js/app.js` | تطبيق عربي RTL |
| **عميل الخادم** | `web/js/api.js` | REST + SSE من الواجهة |
| **طبقة الراوتر** | `web/js/router.js` + `web/js/ubus.js` | اكتشاف الراوتر، الأجهزة، الحظر، الواي فاي، كلمة مرور الراوتر |
| **التطبيق الأصلي** | `android/` | جسر HTTP يتجاوز CORS + اكتشاف البوابة تلقائياً |
| **الاختبارات** | `tools/` | 37 اختبار API · 24 اختبار متصفح · 17 اختبار محرك راوتر |

> **لماذا تطبيق أصلي وليس متصفحاً؟** نقطة `http://<router>/ubus` ترفض طلبات المتصفح
> العابرة للمصدر (CORS) إلا بتفعيل `ubus_cors=1` داخل `uhttpd` — وهذا يتطلب root.
> التطبيق الأصلي (Android) يطلب `ubus` مباشرةً بلا قيود CORS، **بلا root وبلا سيرفر**.

## 2) التشغيل في 30 ثانية

```bash
git clone <المستودع> wifihub && cd wifihub
node server/server.js          # أو: npm start
```

ثم افتح: **http://localhost:8080**

| بيانات الدخول الافتراضية | |
|---|---|
| **اسم مستخدم الإدارة** | `boss` |
| **كلمة مرور الإدارة** | `9876` |

> ⚠️ غيّرها فوراً من: **الإدارة ← بيانات دخول الإدارة** (تُحفظ مُشفَّرة `scrypt` في القاعدة).

### تغيير المنفذ أو مكان القاعدة
```bash
PORT=9000 WIFIHUB_DATA=/var/lib/wifihub node server/server.js
```

### تشغيل دائم (systemd)
```ini
[Unit]
Description=WiFi Hub Server
After=network.target

[Service]
WorkingDirectory=/opt/wifihub
Environment=PORT=8080
Environment=WIFIHUB_DATA=/var/lib/wifihub
ExecStart=/usr/bin/node server/server.js
Restart=always

[Install]
WantedBy=multi-user.target
```

## 3) لوحة الدخول (المشترك)

- تبويب **تسجيل الدخول** + زر **«تذكّرني»** (جلسة 30 يوماً محفوظة على الجهاز؛ بدونه 12 ساعة).
- تبويب **حساب جديد** لأي زبون (يُنشأ في القاعدة فوراً).
- تبويب **المدير** لبيانات `boss / 9876`.

**المشترك المجاني** sees:
- لوحة تحكم مبسّطة + الباقات + زر واتساب + إدخال الكود.
- **كل المميزات مقفلة**: الأجهزة، الاستهلاك، الحظر/التجميد/الحذف/التعليق، تغيير كلمة مرور الواي فاي، تغيير كلمة مرور الراوتر.
- لا تصل إليه بيانات الراوتر إطلاقاً (الخادم يرسلها للبريميوم والمدير فقط).

**المشترك البريميوم** يفتح كل شيء تلقائياً بعد التفعيل:
- عرض الأجهزة المتصلة + حجم بياناتها المستهلكة + حالتها.
- التحكم بها: ❄️ تجميد · 🚫 حظر · 🗑️ حذف (فصل) · ✏️ تعليق (إعادة تسمية).
- **عداد بالأيام المتبقية** من باقته + تاريخ الانتهاء.
- **تغيير كلمة مرور الواي فاي** (اسم/كلمة مرور/نطاق + تدوير) بضغطة زر.
- **تغيير كلمة مرور دخول الراوتر** بضغطة زر — بلا SSH وبلا root على الهاتف وبلا أي IP أو إعداد خارجي.
- حدّ الأجهزة المسموح مطبَّق على الباقة (ما زاد يُوسم «خارج حدود الباقة»).

## 4) دورة الاشتراك (كما يطلب الزبون)

1. يختار الباقة ويضغط **📲 اطلب الباقة** → يفتح واتساب على **963957869853** برسالة مميزة جاهزة:
   ```
   ⭐ *طلب اشتراك WiFi Hub* ⭐
   ━━━━━━━━━━━━━━━━━━━━━━
   📦 *الباقة المطلوبة:* سنة — 365 يوم بسعر 700 ريال
   👤 *اسم المستخدم:* ahmad
   📅 *التاريخ:* 8/11/2026
   ━━━━━━━━━━━━━━━━━━━━━━
   🔑 أرسل لي كود التفعيل وسأدخله في البرنامج،
   عندها تتحوّل حالتي إلى *بريميوم* وتُفتح كل المميزات فوراً.
   ```
   ويُسجَّل الطلب **في القاعدة في نفس اللحظة** فيظهر للمدير لحظياً.
2. المدير يولّد كوداً من **الإدارة ← توليد أكواد الاشتراك**:
   - صيغة `WH-XXXXX-XXXXX-XXXXX-XXXXX` — 20 خانة عشوائية (~100 بت) **صعبة التخمين**.
   - **تُستخدم مرة واحدة فقط**: الاستهلاك يتم ذرّياً داخل القاعدة (`UPDATE … WHERE used_by IS NULL`)
     فلا يمكن إعادة استخدامها حتى مع طلبين متزامنين.
   - تُحدَّد: الباقة · عدد الأجهزة · تاريخ انتهاء الكود · ملاحظة (اسم الزبون).
   - نسخ الكل / تصدير CSV / حذف.
3. يرسل الكود للزبون → يدخله → **يتحوّل فوراً من مجاني إلى بريميوم** وتُفتح كل المميزات
   ويظهر عداد الأيام. (الاشتراك الحالي يُمدَّد ولا يُفقد.)
4. عند انتهاء الباقة يعود تلقائياً إلى **مجاني** وتُقفل المميزات حتى يعيد الاشتراك.

## 5) لوحة الإدارة

| القسم | الإمكانيات |
|---|---|
| **العدّادات** | المشتركون · بريميوم · مجاني · طلبات معلّقة · أكواد متاحة/مستخدمة · متصلون الآن |
| **الطلبات** | تظهر لحظياً؛ زر **✅ تفعيل** (يعتمد الاشتراك ويصل التفعيل للمشترك فوراً) أو **✕ رفض** |
| **بيانات الدخول** | تغيير اسم/كلمة مرور المدير (مُشفَّرة `scrypt`) |
| **توليد الأكواد** | عدد · باقة · أجهزة · انتهاء · ملاحظة · نسخ · تصدير CSV |
| **المشتركون** | حالة (مجاني/بريميوم) · الباقة · تاريخ الانتهاء · **المتبقي بالأيام** · عدد الأجهزة · الكود المستخدم · +30/+90 يوم · تفعيل · حذف |
| **إعدادات الراوتر** | العنوان · المستخدم · كلمة المرور · رقم واتساب · التفعيل التلقائي · إعادة تشغيل الراوتر |

**المزامنة اللحظية:** كل تغيير (تفعيل · كود · طلب · إعداد) يُبَثّ فوراً عبر `SSE`
إلى كل المتصلين — تظهر حالة المشترك في اللوحة **بلا تحديث**، ويصل إشعار «تم تفعيل اشتراكك»
للمشترك **بلا إعادة تحميل**. ومع انقطاع البث يعمل استطلاع احتياطي كل 10 ثوانٍ.

## 6) واجهة البرمجة (API)

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/public/config` | الإعدادات العلنية (الاسم · واتساب · الباقات) |
| POST | `/api/auth/register` | إنشاء حساب مشترك |
| POST | `/api/auth/login` | الدخول (`remember` = تذكّرني) |
| POST | `/api/auth/logout` | الخروج |
| GET | `/api/me` | حالة الحالي (مع بيانات الراوتر للبريميوم/المدير فقط) |
| POST | `/api/redeem` | تفعيل كود (لمرة واحدة) |
| POST | `/api/request` | طلب باقة (يظهر للمدير لحظياً) |
| POST | `/api/me/devices` | رفع قائمة أجهزة المشترك |
| POST | `/api/me/router-password` | مزامنة كلمة مرور الراوتر بعد تغييرها |
| GET | `/api/stream` | قناة الأحداث اللحظية (SSE) |
| GET | `/api/admin/overview` | كل بيانات لوحة الإدارة |
| POST/DELETE | `/api/admin/codes` · `/api/admin/codes/:code` | توليد/حذف الأكواد |
| POST/DELETE | `/api/admin/subscribers/:user/extend` · `/promote` · `/:user` | تمديد/تفعيل/حذف مشترك |
| POST | `/api/admin/requests/:id/approve` · `/reject` | اعتماد/رفض طلب |
| POST | `/api/admin/settings` | الإعدادات + بيانات الإدارة |
| GET | `/api/admin/export/codes.csv` | تصدير الأكواد |

المصادقة: `Authorization: Bearer <token>`.

## 7) البيانات في القاعدة

| الجدول | المحتوى |
|---|---|
| `users` | الحسابات · الدور · الباقة · بداية/نهاية الاشتراك · حدّ الأجهزة · قائمة الأجهزة |
| `codes` | الأكواد · الباقة · الصلاحية · **من استخدمه ومتى** |
| `requests` | طلبات الاشتراك وحالاتها |
| `sessions` | الجلسات (مع «تذكّرني») |
| `settings` | إعدادات التطبيق والراوتر وباقات الاشتراك |
| `events` | سجل الأحداث (تدقيق) |

النسخ الاحتياطي: انسخ مجلد `data/` (أو الملف `data/wifihub.db`).

## 8) بناء التطبيق الأصلي (APK)

```bash
# 1) ضع عنوان الخادم الداخلي في ملف الإعدادات
vim config/app.json
{ "apiUrl": "http://192.168.1.50:8080", "serverPort": 8080 }

# 2) ابنِ الـ APK (لا يحتاج Gradle ولا Android Studio)
cd android && ANDROID_HOME=/path/to/android-sdk ./build.sh

# 3) النتيجة:
android/dist/wifihub.apk
```

- `apiUrl` = عنوان الخادم الذي يتصل به التطبيق (نفس شبكة الراوتر، أو عنوان VPS/نطاق عام).
- إن كان `apiUrl` فارغاً يعمل التطبيق على نفس أصل الخادم.
- يمكن بناءه تلقائياً عبر GitHub Actions (سر `WIFIHUB_API_URL`) — الملف `build-apk.yml`.

## 10) حدود يجب معرفتها

- الراوتر يجب أن يكون **OpenWrt / LEDE** (أو مشتقاً). الراوترات التجارية المغلقة
  (TP-Link/Archer الأصلية) لا تدعم `ubus` — تحتاج راوتراً بديلاً.
- التطبيق يتصل بالراوتر **داخل الشبكة المحلية فقط**؛ خارجها لن يصل (لكن لوحة الإدارة
  والأكواد والاشتراكات تعمل من أي مكان عبر الخادم).
- بيانات الراوتر (المستخدم/كلمة المرور) مخزَّنة في القاعدة؛ احمِ الخادم (HTTPS + كلمة مرور قوية).
- كلمة مرور `root` على الراوتر نقطة القوة الوحيدة: استخدم كلمة مرور قوية ومحدَّثة.
- **غيّر كلمة مرور الإدارة الافتراضية `9876` قبل نشر الخادم.**
